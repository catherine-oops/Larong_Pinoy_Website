# Larong_Pinoy_Website
Larong Pinoy Website is a PHP and MySQL web platform for discovering, preserving, and managing traditional Filipino games through game listings, search filters, user accounts, comments, favorites, play history, and an admin dashboard.


README description:

Larong Pinoy Website

Larong Pinoy Website is a cultural preservation platform designed to promote traditional Filipino games. It allows users to browse different Larong Pinoy games, view game details, learn rules and requirements, check preservation risk levels, and participate through comments, favorites, and play history.

The system includes user registration, login, profile management, favorite games, play session logging, and community comments. It also has an admin dashboard for managing games, users, comments, and preservation risk reports.
